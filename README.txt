# Ecospec Site Survey — Downloadable Web App

## How to use

### Option 1: Open directly (simplest)
1. Unzip this folder
2. Open `index.html` in any modern browser (Chrome, Safari, Edge, Firefox)
3. Fill in the form and tap **Generate Survey PDF**

### Option 2: Install as an App (recommended for field use)

#### On iPhone / iPad (Safari):
1. Open `index.html` in Safari
2. Tap the **Share** button (square with arrow)
3. Scroll down and tap **Add to Home Screen**
4. Tap **Add** — the app appears on your home screen
5. Open it like any app — works offline once installed

#### On Android (Chrome):
1. Open `index.html` in Chrome
2. Tap the **⋮** menu → **Add to Home Screen** (or look for the Install banner)
3. Tap **Add** / **Install**

#### On Desktop (Chrome / Edge):
1. Open `index.html`
2. Click the install icon (➕) in the address bar, or look for the install banner
3. Click **Install**

### Option 3: Host it (for team sharing)
Upload the entire unzipped folder to any web server or hosting service
(GitHub Pages, Netlify, your own server). Share the URL with your team.

---

## Files
- `index.html` — main app
- `manifest.json` — PWA configuration
- `sw.js` — service worker (enables offline use)
- `icon-192.png` / `icon-512.png` — app icons

## Features
- ✅ Works fully offline after first load
- ✅ Generates PDF with photos embedded
- ✅ EXIF photo rotation correction
- ✅ Install to home screen (iOS, Android, Desktop)
- ✅ No server required — runs entirely in the browser
